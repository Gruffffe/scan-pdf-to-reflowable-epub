# 中文出版物 PDF 转可重排 EPUB：结构识别与排版知识

本文件用于指导扫描版或版面复杂的中文出版物从物理页面转换为语义化、可重排的 EPUB。它总结的是通用判断原则，不代替逐书检查，也不要求修改原作者的语言和数字体例。

## 1. 总原则

PDF 保存的是页面；EPUB 需要保存的是阅读结构。转换时应区分：

- 物理结构：页面、坐标、字框、栏、行、页边、装饰线。
- 语言结构：词、短语、句子、复句、句群、段落。
- 篇章结构：篇、章、节、小节、条目、列表、引文、注释、参考文献。
- 阅读结构：封面、前置内容、正文、附录、导航、页码锚点、脚注跳转。

任何单一信号都不应独立决定结构。字号大不一定是标题，缩进不一定是新段，数字不一定是序号，页面底部的文字也不一定是页脚。应组合位置、字体、间距、标点、词法形式、跨页连续性和重复模式。

## 2. 先识别文档类型

在重建前判断文档更接近哪一种：

1. 连续论述：专著、论文、随笔。
2. 教材：章、节、条目、例题、思考题、图表密集。
3. 工具书：词条、释义、例证、参见项。
4. 标准或法规：层级编号、条款、附录、示例。
5. 文言或古籍重排：原文、注释、译文、校勘符号并存。
6. 双语出版物：分册式、对页式、分栏式或逐段对照式。

不同类型使用不同优先级。标准文本优先信任规范编号；论述文本优先信任语义段落；工具书优先信任词条标题；双语文本必须先识别对应模式。

## 3. 标题与层级

### 3.1 常见标题体系

中文出版物常见的层级形式包括：

```text
第一编 / 上编 / 第一部分
第一章
第一节
一、
（一）
1.
（1）
①
a.
```

这只是常见顺序，不是绝对规定。书中实际层级应由目录、字号、缩进、编号连续性和相邻标题共同确认。

### 3.2 标题判断证据

提高标题置信度的信号：

- 与目录文字和页码对应。
- 同级标题具有稳定的编号形式。
- 字号、字重、居中或上下留白明显区别于正文。
- 文本较短，通常不以句号结尾。
- 后续内容出现新的正文段落，而不是同一句的续行。
- 在多页中重复出现同一视觉样式。

降低标题置信度的信号：

- 位于固定页眉区域并在多页重复。
- 是正文中正常出现的“第一”“第二”或年份。
- 文字很长且语法上明显承接上一行。
- 只因 OCR 行高异常而显得字号较大。

### 3.3 EPUB 映射

- 篇或部分：导航分组或 `part`。
- 章：独立 XHTML，使用 `h1`。
- 节：同章内使用 `h2`，必要时进入目录。
- 更低层级：使用 `h3`、`h4` 或语义化列表。
- 不要仅为了视觉放大而滥用标题元素。

## 4. 行、句子、句群与段落

### 4.1 物理换行不等于段落

扫描书的每一行是排版结果，不是语义段落。OCR 行通常应先按阅读顺序合并，再判断段落边界。

中文同一段内的物理换行通常直接拼接，不插入空格；英文行间一般需要补空格。中英混排时根据相邻字符类型决定是否插入空格。

### 4.2 段落的语义原则

一篇文章可以有总中心，一个自然段通常围绕一个较小的中心或一个连续的论述任务展开。段落长短本身不能作为判断标准。常见段落组织依据包括：

- 时间推进。
- 空间位置变化。
- 事理或论证层次变化。
- 叙述对象或观察点变化。
- 提出观点、解释观点、举例、转折、总结。

因此，自动断段应结合版面证据和语义连续性，不能仅依赖句号数量或段落长度。

### 4.3 新段证据

强证据：

- 首行缩进稳定地比正文基线更深。
- 段前垂直间距明显增大。
- 上一行已经完成句子，下一行出现新的论述标记。
- 下一行以“首先、其次、然而、因此、总之”等篇章连接词起始，同时有缩进或间距支持。
- 列表、引文、定义、例证等语体发生变化。

弱证据：

- 下一行首字看起来像数字。
- OCR 行突然变短。
- 页面换页。
- 行高轻微变化。

弱证据不能单独触发断段。

### 4.4 跨页合并

页面结束时，若最后一行没有形成完整句法单位，下一页第一条正文应作为同段续接。可参考：

- 句末是否缺少句末点号。
- 下一页是否以虚词、宾语、补语或关联成分承接。
- 页首文字是否是重复页眉。
- 前后是否属于同一列表项、引文、脚注或参考文献。

换页不能自动增加空格、句号或新段。

## 5. 标点与句界

### 5.1 句界判断

句号、问号、叹号通常表示句子完结，但应结合语气和引号、括号状态。逗号、顿号、分号和冒号通常不构成段落边界。

- 问句中出现疑问词，不代表一定使用问号；应看整句是否具有疑问语气。
- 选择问句通常在最后一项使用问号，但原文可能有强调性例外。
- 冒号的管辖范围可能覆盖一句、数句或数段，不应在冒号后机械切断结构。
- 分号常用于区分内部已有逗号的并列分句或条目。

### 5.2 不应轻率自动纠正的字符

- 中文引号与英文引号。
- 全角括号与半角括号。
- 破折号、连接号和负号。
- 省略号与多个句点。
- 书名号与尖括号。
- 间隔号与小数点。

只有在字形、上下文和规范三方面均有较强证据时才纠正 OCR。否则保留原识别并列入人工复核。

### 5.3 标点的行首行末

不要在 XHTML 中用硬换行模拟原书避头尾规则。交给阅读器重排；必要时使用通用 CSS 行分割属性。不可将标点从原句中拆成独立段落。

## 6. 数字用法与数字保护

本节参考 GB/T 15835-2011。该标准的核心是表达得体和同类形式一致，而不是无条件把数字统一成阿拉伯数字。

### 6.1 常见语义类别

- 计量、统计、百分比、比值和精确数值通常使用阿拉伯数字。
- 定型词语、成语、历史称谓等组成部分通常保留汉字数字。
- 年月日、时分秒、年龄、页码、编号等应按原书体例和上下文判断。
- 相邻两个数字表示概数时通常使用汉字，中间不加顿号，如“二三十年”。
- 同一场合同类别数字应保持同一形式；不同功能或不同层级可使用不同形式。

转换任务原则上保留原文数字形式，不主动进行编辑式改写。规范主要用于识别和防止错误断行。

### 6.2 不应拆开的数字单元

以下内容尽量保持为同一文本单元，避免在内部插入段落或无意义空格：

- 年月日和时间。
- 带计量单位的数值。
- 百分比、分数、比例和小数。
- 数值范围。
- 标准号、文件号、卷期号、ISBN、DOI 等代码。
- 引文页码和参考文献的卷、期、页范围。

可以使用非断行空格或适度的 `white-space: nowrap` 保护短数字单元，但不要让很长的字符串溢出小屏幕。

### 6.3 OCR 常见混淆

```text
1 ↔ I ↔ l ↔ ! ↔ ' ↔ ①
0 ↔ O ↔ 〇
2 ↔ Z
5 ↔ S
— ↔ - ↔ 一
. ↔ · ↔ 。
```

纠正前先判断数字所处的语义类别。正文中的“1”可能是数量、年份的一部分、章节编号、脚注标记或例句编号，不能看到数字就断行。

## 7. 序次语与列表

### 7.1 常见序次语

- 不带括号的汉字序次语常见形式为“一、”。
- 加括号的汉字序次语常见形式为“（一）”，后面不再添加点号。
- 不带括号的阿拉伯数字或拉丁字母序次语常见形式为“1.”、“A.”。
- 加括号的阿拉伯数字常见形式为“（1）”，后面不再添加点号。
- 章节编号如“3.1”之后一般直接接标题，不再增加点号。

### 7.2 结构判断

序次语必须满足至少两项证据：

- 位于行首或固定列表缩进位置。
- 与前后项目形成连续序列。
- 后续文字在同一缩进层级。
- 上文有提示语、冒号或列表标题。
- 同页或邻页存在相同格式的其他项目。

单独出现的数字不应自动生成列表。`（一）`、`1.`、`（1）`属于不同层级时，应嵌套为 EPUB 列表或相应小标题。

## 8. 页码、页眉与页脚

### 8.1 页码识别

页码通常具有以下组合特征：

- 位于上、下页边固定区域。
- 字符短，常为阿拉伯数字、罗马数字或汉字页码。
- 随物理页单调递增。
- 奇偶页位置可能镜像。
- 与正文栏之间有稳定距离或装饰元素。

正文中的孤立数字只有同时满足页边和序列证据时才能删除。

### 8.2 EPUB 页码锚点

删除扫描页码文字后，可在对应正文位置添加：

```html
<span epub:type="pagebreak" id="page-37" title="37"></span>
```

应区分 PDF 文件页码与原书印刷页码。封面、版权页和目录可能使用不同编号系统或不编号。锚点标题优先使用原书印刷页码，内部 ID 必须唯一。

### 8.3 页眉页脚

页眉页脚应通过跨页重复模式识别：

- 奇数页可能显示章名，偶数页显示书名。
- 页眉文字与正文标题相同，不代表每页重新开始一章。
- 只在固定页边出现的出版信息、扫描标记和网站水印属于清理候选。
- 若页边文字只出现一次，它可能是边注、图注或正文，不可直接删除。

## 9. 脚注、尾注与角注

### 9.1 脚注区域证据

典型脚注同时具有多项特征：

- 位于页面下部。
- 与正文之间存在水平分隔线或明显留白。
- 字号小于正文。
- 以数字、圈码、星号或其他标记起始。
- 正文存在对应的上标标记。
- 多条注释的编号顺序合理。

水平线本身不是充分证据；表格线、装饰线也可能被误判。

### 9.2 正文标记与注释编号

脚注编号可能是 `1`、`①`、`*` 等。必须与正文位置联合判断：

- 正文标记通常字号较小、基线较高，并紧邻被注释文字。
- 列表编号通常位于行首并有固定缩进。
- 页码位于页边。
- 数量和年份处于正常基线并属于句法成分。

若 OCR 只有整行边界、没有字符级边界，应采取保守匹配。找不到可靠正文标记时，保留注释内容但不要把普通数字强行链接成脚注。

### 9.3 EPUB 脚注结构

```html
正文<a epub:type="noteref" id="ref-1" href="#note-1"><sup>1</sup></a>

<aside epub:type="footnote" id="note-1">
  <p><sup>1</sup> 注释内容 <a href="#ref-1">↩</a></p>
</aside>
```

脚注可以保留在对应章节末尾，以兼容不支持弹出脚注的阅读器。

### 9.4 角注和边注

角注或边注通常位于正文栏外侧，并在垂直方向与被注释文字对齐。处理优先级：

1. 有明确锚点时转换为 `aside` 并链接。
2. 无法可靠对齐时放入本节“边注”区域，并保留来源页码。
3. 若角注主要是装饰、索引提示或章名导航，应根据全书重复模式决定保留或删除。

不要把边注插入最近的一行正文；这容易破坏句法。

## 10. 引文、例句、定义与参考文献

### 10.1 引文

- 行内短引文保留引号并留在段落内。
- 独立引文通常具有左右缩进、较小字号或独立上下间距，转换为 `blockquote`。
- 引文末尾的出处若位于独立行，可使用 `cite` 或单独的出处段落。
- 引号内的段落边界应按原文保留，不能把每一物理行转成一个引文段。

### 10.2 例句和题目

语法、语言学教材常用 `①`、`（甲）`、`*`、`?` 等标识例句性质。它们不一定是脚注：

- 位于正文栏、连续排列、后接完整例句时，通常是例句编号。
- 位于左上角的星号或问号可能表示句子不成立或可疑，应与例句整体保留。
- 例句后的解释、译文和语法分析可能属于同一条目的子层级。

### 10.3 定义和术语

“术语 + 解释”“编号 + 术语 + 定义”宜保留为定义列表或稳定段落，而不是把术语与解释合并成无结构文本。

### 10.4 参考文献

- 按条目而不是按扫描行分段。
- 跨页续行应并入上一条目。
- 使用悬挂缩进。
- 保护作者、年份、卷期、页码、ISBN、DOI 和 URL 的内部连续性。
- 引文页码和参考文献编号通常是阿拉伯数字，但不能因此被识别为脚注。

## 11. 图片、表格、图注和公式

### 11.1 保留图片的条件

优先保留：

- 封面、书名页中不可替代的视觉设计。
- 地图、流程图、结构图、插图和照片。
- 不能可靠转为语义表格的复杂表格。
- 公式密集且 OCR 无法可靠表达的区域。

正文不能整体做成逐页图片 EPUB。

### 11.2 图片与图注

- 裁去无意义页边，但不要裁掉编号和图例。
- 使用足够分辨率，兼顾 Kindle 屏幕和文件大小。
- 图注应作为文本保留，并与图片形成 `figure` / `figcaption` 关系。
- 能提供准确简短描述时填写 `alt`；装饰图片使用空 `alt`。

### 11.3 表格

规则表格可重建为 HTML 表格；复杂跨栏表格可保留图片，并将标题和必要说明转为文本。小屏幕上应允许横向滚动或采用适当降级方案。

## 12. 双语版识别

先判断双语组织方式：

1. 完整甲语言部分 + 完整乙语言部分。
2. 左右对页。
3. 同页双栏。
4. 逐段对照。
5. 逐句或逐条对照。

不得仅因同一本书出现两种语言，就擅自重组为逐段对照。

- 分部式：分别建立语言分组和章节，设置 `lang`。
- 对页式：依据印刷页配对，必要时提供“按语言连续阅读”和“对照阅读”两种结构。
- 分栏式：先完成栏检测，再按栏读取；不能按整页横向坐标交错拼接。
- 逐段式：利用标题、编号、段落数量和长度建立对应关系，低置信度时保留原顺序。

## 13. 建议的置信度模型

每个结构判断保存证据，而不是只保存结果。

### 标题分数

- 目录匹配：高权重。
- 编号连续：高权重。
- 字号和留白：中权重。
- 文本短：低权重。

### 段落边界分数

- 稳定首行缩进：高权重。
- 明显段前间距：中权重。
- 上一句完整 + 新论述标记：中权重。
- 单纯换页或数字开头：不得单独触发。

### 脚注分数

- 正文上标与页下注释编号匹配：高权重。
- 分隔线 + 小字号 + 页底位置：高权重组合。
- 只有页底位置：低权重。

### 页码分数

- 页边固定位置 + 连续序列：高权重。
- 单个孤立数字：低权重。

低置信度结构应记录到审计报告并进入人工抽样，不应静默猜测。

## 14. 质量检查

### 14.1 必测样本

- 封面与书名页。
- 原书目录与 EPUB 导航。
- 每一级标题至少一处。
- 普通正文和跨页段落。
- 含年份、数量、序次语的页面。
- 含脚注、角注或例句编号的页面。
- 引文、参考文献、图表。
- 双语切换或对照位置。
- 古文、异体字、繁简混排等特殊页面。

### 14.2 结构不变量

- 目录顺序与 spine 一致。
- XHTML ID 唯一。
- 每个脚注链接指向存在的目标；返回链接只在正文锚点存在时生成。
- 页码锚点单调、有唯一 ID，且不显示为正文噪声。
- 图片资源均在 manifest 中并可达。
- CSS 路径相对于 XHTML 正确。
- EPUBCheck 无 fatal、error 或 warning。

### 14.3 报告措辞

区分以下结论：

- “自动识别完成”：流程运行完毕。
- “抽样核对通过”：只代表列明的样本。
- “结构校验通过”：EPUB 包结构有效。
- “逐字校对完成”：只有真正逐页逐字复核后才能使用。
- “实机测试通过”：只有实际导入目标设备后才能使用。
