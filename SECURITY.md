# Security policy

This skill processes documents on the user's machine by default. It must not
upload source pages, OCR text, credentials, or generated books unless the user
explicitly authorizes a specific external service.

## Reporting a vulnerability

Please use the repository's **Security** tab to open a private security
advisory. Do not put private documents, credentials, local paths, or exploit
details in a public issue.

Useful reports include the affected file and version, a minimal reproduction
using synthetic data, expected behavior, and observed behavior.

## Supported version

Security fixes are applied to the latest revision on the default branch. This
repository does not bypass DRM, passwords, encryption, or access controls.
